# 好孕日记 · 孕期检查记录

一个纯离线的孕期记录小工具，帮助准妈妈记录孕周、体重、血值（HCG / 孕酮）、产检结果和检查报告照片。

整个应用只有一个 `index.html`（HTML + CSS + 原生 JavaScript，无框架、无构建步骤、无网络请求），既可以直接用浏览器打开，也可以打包成 Android APK 离线使用。

## 为什么做这个软件

因为媳妇怀孕了。

整个孕期要做十几次产检，每次的孕周、血值、体重、B 超指标和检查报告单，散落在手机相册、聊天记录、纸质单据和各类 App 里，想回头对比一次数据都要翻半天。而大多数孕期 App 又充斥广告、社区和推销，真正需要的记录功能反而藏得很深。

所以就自己写了一个：只做一件事——把每一次产检完整、清楚地记下来。打开就能看到现在孕几周、下一项检查是什么、这次的指标和上次相比有没有变化，报告照片也能和记录放在一起，随时翻看。

没有账号、没有广告、不联网，数据只留在自己手机上。它先是为了方便家人记录，也希望能帮到同样在孕期的你。

## 功能

### 概览

- 根据末次月经自动计算当前孕周、预产期和孕期进度
- 快捷记录 HCG / 孕酮、新增产检记录
- 体重摘要：当前体重、累计增重、孕前 BMI 与推荐增重区间提示
- 最近血值：HCG 较上次翻倍倍数、孕酮变化
- 下一项产检提醒（按孕周区间自动推算）
- 最近记录列表

### 指标

- 血值趋势图：HCG 与孕酮双 Y 轴折线图（Canvas 手绘，可点击查看数据点）
- 体重曲线：按孕周绘制，叠加推荐增重上下限
- 体重记录支持编辑、删除

### 产检

内置 13 类检查模板，按类型自动带出常用指标项：

| 检查             | 建议孕周    |
| ---------------- | ----------- |
| 早孕 B 超        | 6–8 周     |
| NT 检查          | 11–13+6 周 |
| 唐氏筛查         | 15–20 周   |
| 无创 DNA（NIPT） | 12–22 周   |
| 羊水穿刺         | 16–22 周   |
| 大排畸 B 超      | 20–24 周   |
| 糖耐量试验 OGTT  | 24–28 周   |
| 血尿常规         | 每次产检    |
| 甲功 / 肝肾功能  | 孕早期      |
| 胎心监护 NST     | 32 周起     |
| 孕晚期 B 超      | 30–40 周   |
| GBS 筛查         | 35–37 周   |
| 其他检查         | 自定        |

- 产检计划按孕周自动标注「待做 / 进行中 / 已过期」等状态
- 指标项可自由增删，支持单位与备注
- 报告照片：支持直接拍摄或从相册选择，自动压缩后保存；支持缩略图、全屏查看、左右切换，单条记录最多 12 张

### 时间线

血值、体重、产检记录合并后按日期倒序展示，并标注对应孕周。

### 设置

- 编辑孕期档案（昵称、末次月经、预产期、身高、孕前体重）
- 数据统计：血值 / 体重 / 产检条数、报告照片数量与占用空间
- 导出 JSON 备份、导入备份、导出 CSV 表格、清空数据

## 数据与隐私

- 所有数据仅保存在本机 `localStorage`（键名 `haoyun_journal_v1`），不会上传到任何服务器。
- 浏览器 `localStorage` 通常只有约 5 MB 配额，报告照片过多会触发「存储空间不足」提示；建议定期导出备份并控制照片数量。
- 换设备、清理浏览器数据或卸载应用前，请先在「设置」中导出 JSON 备份。
- 报告照片压缩参数：长边 1400 px、JPEG 质量 0.78，另存 220 px 缩略图。

### 数据结构

```json
{
  "profile": { "name": "", "lmp": "", "edd": "", "height": "", "preWeight": "" },
  "labs":    [{ "id": "", "date": "YYYY-MM-DD", "hcg": "", "prog": "", "note": "", "created": 0 }],
  "weights": [{ "id": "", "date": "YYYY-MM-DD", "kg": "", "note": "", "created": 0 }],
  "exams":   [{
    "id": "", "date": "YYYY-MM-DD", "type": "us1",
    "hospital": "", "result": "",
    "items":  [{ "n": "指标名", "v": "结果", "u": "单位" }],
    "images": [{ "data": "data:image/jpeg;base64,...", "thumb": "data:image/jpeg;base64,...", "w": 0, "h": 0 }],
    "note": "", "created": 0
  }]
}
```

JSON 备份文件带 `app: "haoyun-journal"` 标识，导入时会做字段归一化，兼容早期版本数据。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装依赖或启动服务。

也可以起一个静态服务器（便于手机同局域网访问）：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

首次打开时可在概览页点击「载入示例数据看看」预览完整效果（会追加示例血值、体重和产检数据）。

## Android APK 构建

APK 采用「WebView 壳 + 单文件页面」方案，未使用 Gradle / Capacitor，构建依赖本地 SDK 手动完成。

- 包名：`comliulian.haoyun`
- 当前版本：`versionCode 3` / `versionName 1.2.1`
- `minSdkVersion 24`（Android 7.0）、`targetSdkVersion 34`
- 应用无网络权限；仅声明 API 32 及以下的读写存储权限，文件保存/选择通过 SAF 完成

构建流程：

1. 将最新的 `index.html` 复制为 `apk-build/app/assets/index.html`
2. 用 `aapt2 compile` / `aapt2 link` 编译并链接资源，生成未签名 APK 与 `R.java`
3. `javac` 编译 `MainActivity.java`（注意：直接 javac 编译不支持 lambda，需用匿名内部类），再经 `d8` 生成 `classes.dex` 并放入 APK
4. `zipalign` 对齐后，用 `apksigner` + `apk-build/release.keystore` 签名

已签名的成品 APK 输出到项目根目录或 `bak/` 目录。升级安装时保持同一签名，可直接覆盖安装并保留本地数据。

构建注意：`aapt.exe` 处理中文文件名参数时会编码错乱，验证或脚本传参时先复制为 ASCII 临时文件名。

### 原生桥能力

`MainActivity` 在 WebView 中暴露 `AndroidBridge`，并对页面提供以下支持：

- `AndroidBridge.saveFile(filename, base64, mime)`：弹出系统「另存为」，写入导出文件（JSON / CSV）
- `onShowFileChooser`：让页面的 `<input type="file">` 能唤起系统文件选择器（导入备份、选择照片）
- `onJsAlert` / `onJsConfirm`：页面 `alert()`、`confirm()` 弹窗正常显示
- 返回键优先回退网页历史，状态栏颜色与页面主题一致
- 启用 JavaScript 与 DOM Storage（`localStorage` 持久化）
